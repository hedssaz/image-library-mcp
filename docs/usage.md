# 连接并使用表情包

[返回 README](../README.md)

## 1. 把 MCP 加到客户端

找到客户端的 MCP 设置，添加一个远程服务。连接类型选 **Streamable HTTP**，填写部署得到的地址，例如：

```text
https://你的服务地址/mcp
```

需要填请求头时，名字是 `Authorization`，值是 `Bearer ` 后面接你的 key：

```text
Authorization: Bearer my-cat-2026
```

如果页面直接提供“Bearer token”输入框，通常只填 `my-cat-2026`，按客户端提示操作。

优先使用 `Authorization` 请求头。只有 URL 输入框、不能填请求头的客户端，也可以这样连接：

```text
https://你的服务地址/mcp?token=my-cat-2026
```

URL 中的 key 可能进入客户端、反向代理或监控日志，以及浏览器历史；拿到 key 的人可以修改、删除图库。必须用 URL 参数时，关闭完整请求 URL 日志或对 `token` 脱敏，不要分享含 key 的链接。

把示例 key 换成自己的。key 如果含 `&`、`#`、`+` 等符号，用请求头更省事；放进 URL 时需要让 AI 帮你做 URL 编码。两个地方都填时，以请求头为准。

连接成功后，应能看到 `search`、`get`、`show_image`、`add`、`addalias`、`delete` 六个工具。

## 2. 添加自己的图片

图库最初是空的。准备一个可直接打开图片的链接，对 AI 说：

> 把这个图片链接收藏到表情包库，名字叫“开心猫”，别名加上“开心、哈哈”，描述写“开心或觉得好笑的时候用”。

把实际图片链接附在后面。它应该是图片文件链接，而不是需要登录的分享页。

也支持 Base64 添加。客户端能否读取你上传的附件，取决于客户端能力；不能直接读取时，可以先用图片链接。

## 3. 直接聊天调用

例如：

> 给我发一张开心的表情包。

> 看看我现在有哪些表情包。

> 给“开心猫”加一个“笑死”的别名。

> 删除“开心猫”这张图片。

AI 会先搜索，再按准确名字展示。支持 MCP Apps 的客户端会显示卡片；不支持的客户端可以尝试使用原图内容或外链，实际显示方式由客户端决定。

单张图片最大 10 MiB，支持 PNG、JPEG、GIF、WebP，并保留动图。名字、别名和描述写得清楚，AI 更容易找到合适的图。

## 多平台和多个对话怎么用？

在各个支持的客户端配置**同一个 MCP 地址和 key**，就能共用同一套表情包，不用为每个对话重新准备整套图库。

图片展示仍会从远程加载，可能比直接发送已经下载好的图片慢。默认展示工具还会把原图交给模型；想关闭这部分内容，看[可选设置](advanced.md#是否把原图交给-ai)。

## 连不上时先看这里

| 情况 | 怎么处理 |
| --- | --- |
| 401、key 无效 | 核对两边的 key，并检查 `Bearer` 后面有一个空格 |
| 云端客户端连不上本地地址 | `127.0.0.1` 指客户端自己；需要它能访问的服务地址 |
| 找不到任何图片 | 先添加图片；或让 AI 用空关键词列出图库 |
| 搜索正常，卡片不出现 | 确认客户端支持 MCP Apps，也可以先尝试图片外链 |
| 删除后旧卡片还能看到 | 旧图片可能被浏览器缓存；不代表还在图库里 |

图片外链不需要 key，拿到链接的人也能访问。项目按个人自部署使用设计。
